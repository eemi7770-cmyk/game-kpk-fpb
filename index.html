⚙ Pengaturan guru · Hubungkan Google Drive

Penting: HTML saja tidak dapat menulis ke Drive atau mencegah pengulangan lintas perangkat. Hubungkan Google Apps Script di bawah untuk menyimpan nilai di Google Sheets dalam Drive dan mengunci satu kesempatan berdasarkan NIS. Mode lokal hanya mengunci di browser ini dan dapat dihapus lewat data browser.

  1. Buat Google Spreadsheet kosong di Drive, lalu buka Ekstensi → Apps Script.
  2. Salin kode berikut. Isi SHEET_ID dengan ID dari URL spreadsheet, serta tentukan EXAM_ID yang unik untuk ujian ini.
  3. Pilih Deploy → New deployment → Web app. Jalankan sebagai diri sendiri; izinkan akses Anyone jika kebijakan sekolah memungkinkan. Otorisasi akses spreadsheet.
  4. Tempel URL deployment berakhiran /exec di bawah, lalu simpan. Pengaturan berlaku di browser ini; untuk distribusi ke siswa, isi konstanta DEFAULT_ENDPOINT dalam HTML dengan URL yang sama.

Gunakan daftar NIS resmi di sheet Siswa, kolom A mulai baris 2. Backend menolak NIS yang tidak terdaftar. Kunci NIS bukan autentikasi: untuk ujian berisiko tinggi, gunakan akun sekolah atau sistem login. Jangan membagikan spreadsheet nilai kepada siswa.
